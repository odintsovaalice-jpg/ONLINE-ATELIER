# ATELIER — 3D-конфигуратор одежды

Все файлы проекта находятся в корне репозитория — папка `src` не нужна.

## Файлы
- `index.html` — HTML-точка входа.
- `main.jsx` — запуск React-приложения.
- `App.jsx` — интерфейс конфигуратора.
- `Scene.jsx` — 3D-сцена и процедурные модели.
- `catalog.js` — каталог категорий, моделей, тканей и декора.
- `styles.css` — оформление интерфейса.
- `package.json` — зависимости и команды.
- `vite.config.js` — конфигурация сборки.
- `.gitignore` — исключения для Git.

## Запуск локально
Требуется установленный Node.js 18 или новее.

```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```
Vite создаст папку `dist` автоматически. Её не нужно загружать в GitHub вручную, если Cloudflare Pages собирает сайт из исходников.

## Cloudflare Pages
- Framework preset: `Vite`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/` (корень репозитория)

## Важно о моделях
В этом прототипе геометрия одежды создаётся процедурно в Three.js. Это интерактивные демонстрационные формы, а не точные выкройки или фотореалистичная симуляция ткани. Для коммерческого уровня реализма следующий этап — детализированные 3D-модели с UV-развёрткой и отдельными зонами для нанесения декора.
