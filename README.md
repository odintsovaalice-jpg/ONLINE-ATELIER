# ATELIER — 3D-конфигуратор онлайн-ателье

Рабочий фронтенд-прототип на React + Vite + Three.js / React Three Fiber.

## Что работает
- 6 категорий: платья, жакеты и костюмы, брюки и юбки, блузы, верхняя одежда, сумки.
- Несколько программно созданных 3D-моделей в каждой категории.
- Вращение модели мышью/касанием, приближение и отдаление.
- Переключение между отдельным изделием и демонстрацией на стилизованном манекене.
- Изменение цвета и материала в реальном времени.
- Демонстрационные элементы декора с выбором расположения.
- Сохранение конфигурации в JSON.
- Адаптивный интерфейс.

## Запуск
Требуется Node.js 18+.
```bash
npm install
npm run dev
```
Проверка production-сборки:
```bash
npm run build
```

## Cloudflare Pages
1. Загрузите файлы проекта в корень GitHub-репозитория.
2. В Cloudflare Pages подключите репозиторий.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Framework preset: Vite.

## Честно о моделях
3D-изделия в этой версии генерируются процедурно непосредственно кодом: это интерактивные объёмные геометрические заготовки для проверки UX и логики конфигуратора. Это не фотограмметрия, не профессиональные выкройки и не физически точная симуляция ткани. Для коммерческого фотореалистичного результата понадобится заменить заготовки на отдельные подготовленные GLB/GLTF-модели с UV-развёрткой и зонами нанесения принтов/вышивки.

## Структура
- `src/App.jsx` — интерфейс и состояние.
- `src/Scene.jsx` — 3D-сцена и процедурные модели.
- `src/catalog.js` — каталог моделей, материалов и декора.
- `src/styles.css` — оформление.
